# @deepseek-ai/dsh-client-ui-message-navigator

[English](README.md) | 中文

消息导航是纯浏览器消费方，在 Chat 旁边贡献可选的 `conversation.session.navigator` slot。它从当前已加载的 `snapshot.chat` 顺序中投影已完成的用户消息与 steering 行，并使用 Chat view 的稳定行锚点；它不添加会话事件、服务或持久化状态。

每个导航项静止时显示 16px 横向锚点。指针悬停或键盘聚焦时，锚点保持原位，并在其左侧显示与锚点中心对齐的预览气泡；首尾导航项会将气泡向列表内部对齐，确保其完整可见。气泡最多两行、每行 15 个字符：内容经空白规范化后保留 24 个 Unicode 代码点，仍有内容时尾随 `......`。滚动会选中已越过阅读区顶部偏移量的最后一条用户消息；点击导航项会把对应锚点滚动到相同偏移量。导航仅在 Chat 为活动视图时渲染。

## 模型体验

无。导航投影浏览器会话历史；这里没有任何内容进入模型请求。

#### KV Cache 影响

无；该包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **只能导航已加载的 Chat 窗口**：当前历史页之前的记录会在 Chat view 加载该页后获得导航项。
- **非文本内容没有行内摘要**：仅含图片的消息仍保留可导航标记，并显示本地化的空消息无障碍标签。
